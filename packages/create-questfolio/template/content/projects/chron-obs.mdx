**ChronOBS** is a lightweight synchronization tool designed for **League of Legends esports broadcasts**. It helps multiple broadcast operators keep their production environments synchronized by sharing events and state changes in real time.

The application connects to the **League of Legends Client API** to retrieve live game information and distributes relevant data through **MQTT**, allowing different OBS operators and production machines to stay aligned during a broadcast.

The project was created to simplify coordination between observers and broadcast operators, reducing manual communication and minimizing synchronization errors during live productions.

This project was built with **Python** and uses **MQTT** as its messaging layer to provide reliable communication between production clients.
