The **HackEPS 2020 Discord Bot** was built to run the official Discord server for **HackEPS 2020**, forked and adapted from LleidaHack's hackathon bot base to fit that year's event.

The codebase is split cleanly by responsibility: a `crud` layer for data persistence, `models` defining the underlying schemas, `modules` holding the actual bot commands and behavior, and a `texts` module keeping every user-facing message in one place instead of scattered across the command logic. It ships with a `Dockerfile` for containerized deployment and a small unit test suite runnable via `python -m unittest`.

Written in **Python** on top of **discord.py**, the bot handled the day-to-day of keeping hundreds of hackers coordinated in a single server — the kind of unglamorous infrastructure that mostly needs to just work for 48 straight hours without anyone noticing it's there.
